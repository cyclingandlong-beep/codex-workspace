# codex-workspace

A public workspace repository for **OpenAI Codex** to read, edit, and iterate on small projects.

Owner: [@cyclingandlong-beep](https://github.com/cyclingandlong-beep)

## Purpose

This repo exists so Codex can work against a real Git repository: clone it, make changes,
open pull requests, and keep a history. It is intentionally kept **small and public**.

## Ground rules

Because this repository is **public**, the following must never be committed here:

- unpublished research data, manuscripts, or thesis material
- personal information (real name, email, student ID, addresses)
- credentials, API keys, tokens, or private configuration files
- large binaries or datasets

If a project needs any of the above, use a **private** repository instead.

## Layout

```
codex-workspace/
└── README.md      ← this file
```

Subfolders are added as projects appear, one directory per project.

## Using it with Codex

1. Point Codex at this repository (GitHub connection, or clone the URL below).
2. Work on a branch, then open a pull request.
3. Keep changes scoped: one project per directory, no secrets, no data.

Clone URL:

```
https://github.com/cyclingandlong-beep/codex-workspace.git
```
